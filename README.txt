# Bakelite Defence: Telegram-бот

Помогает пострадавшим от киберпреступлений и набирает защитников (OSINT-специалистов).
Один файл `index.js`, одна зависимость (`telegraf`). Данные хранятся в `data/db.json`.

## Запуск на Windows (по шагам)

1. Установите Node.js 20 или новее: https://nodejs.org (кнопка LTS).
2. Создайте бота: в Telegram откройте **@BotFather**, команда `/newbot`, скопируйте токен.
3. Узнайте свой ID: напишите **@userinfobot**, он ответит числом. Это ваш `ADMIN_CHAT_ID`.
   Если заявки должны приходить в группу: добавьте бота в группу админом, затем добавьте в группу @userinfobot или @getidsbot, он покажет ID группы (начинается с `-100`).
4. В папке проекта в PowerShell:
   ```powershell
   Copy-Item .env.example .env
   notepad .env        # вставьте BOT_TOKEN и ADMIN_CHAT_ID, сохраните
   npm install
   npm start
   ```
5. Откройте своего бота в Telegram и нажмите **Start**. Один раз напишите ему из того аккаунта, который будет админом, иначе он не сможет вам писать в личку (нужно для кнопки «Ответить»).

В консоли должно появиться `✅ Bakelite Defence v5.0.0 запущен как @имя_бота`.

## Настройки (.env)

| Переменная | Нужна | Зачем |
|---|---|---|
| `BOT_TOKEN` | да | токен от @BotFather |
| `ADMIN_CHAT_ID` | да | куда приходят заявки и обращения |
| `AI_BASE_URL`, `AI_API_KEY`, `AI_MODEL` | нет | ИИ-помощник (любой OpenAI-совместимый API, например Groq). Без них раздел даёт короткий чек-лист |
| `VIRUSTOTAL_API_KEY` | нет | дополнительная проверка ссылок |
| `DATA_DIR` | нет | где хранить данные (по умолчанию `./data`) |

Файл `.env` и папку `data` не заливайте на GitHub (добавьте их в `.gitignore`). Если токен случайно попал в чат или репозиторий, отзовите его у @BotFather командой `/revoke`.

## Хостинг

Бот работает через long polling, ему нужен процесс, который не засыпает: свой ПК, VPS, Railway, Render (Background Worker), Fly.io. На Vercel он не заработает (там нет постоянно работающих процессов). Для автоперезапуска на VPS: `npm i -g pm2 && pm2 start index.js --name bakelite`.

## Проверка

`npm test` прогоняет 22 сценария на имитации Telegram: меню, анкета и тест, одобрение, обращения, приоритеты, кнопки админа, статус, база знаний, ИИ, ссылки, права доступа.

## Команды

`/start` `/menu` `/report` `/join` `/status` `/help` `/cancel` `/delete`. В админ-чате ещё `/stats`.
